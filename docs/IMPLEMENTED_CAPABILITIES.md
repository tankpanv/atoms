## 使用条件与能力边界

| 能力 | 当前实现范围 |
| --- | --- |
| AI 构建 | 需要配置可用的模型地址、模型 ID 和 API Key；清单表示已有执行能力，不保证任意需求自动完成。 |
| App 类型 | 已有类型选择及通用项目构建流程；不等同于移动原生应用打包、应用商店上架。 |
| 浏览器验收 | 用户可选择是否向模型开放浏览器交互工具；Web 交付的实际 JavaScript 启动检查仍执行。普通档与深度 / 高级档的业务验收范围不同。 |
| 图片和语音 | 图片理解依赖所选模型能力或本地视觉服务；语音需要转写接口以及浏览器麦克风权限和安全上下文。PDF 附件提取文字，不包含扫描件 OCR。 |
| 文件成果 | 成果由 Agent 编码生成，Office 版式转换需要运行环境中的 LibreOffice 等依赖。XLS 支持转换后的分页预览，表格数据浏览支持 XLSX / CSV，不提供在线 Office 编辑。 |
| 版本还原 | 还原源码、执行会话及运行配置；不还原业务数据库、用户浏览器存储、项目密钥、聊天审计记录或已发布站点。 |
| 发布后端 | 发布使用冻结代码和依赖的独立容器，镜像与前端资源归档至 MinIO，生产数据与开发数据隔离；发布版本回退保留生产数据，不撤销业务写入或数据库迁移。 |
| 发布应用存储 | 沙盒提供 Web Storage 桥接，支持自定义服务路由与 WebSocket；依赖 Cookie 登录、IndexedDB、Service Worker 的应用仍需额外兼容支持。 |
| 自定义域名 | 已有域名管理、真实 DNS 验证及 Host 路由；公网反向代理和 TLS 证书需要部署配置，未将自动购域名或自动签发证书列为实现。 |
| GitHub | OAuth 和仓库读写需要管理员配置及用户授权；平台项目删除不会删除远程仓库。 |
| 账户偏好 | 已保存语言、声音和邮件通知等偏好；偏好持久化不等于完整双语页面、邮件发送或通知中心。 |
| 订单支付 | 当前为明确标注的本地模拟支付，账本和订单真实持久化；未接入真实收款或财务发票服务。 |
| 工作区 | 工作区资料已实现；未将团队邀请、成员角色、多用户协同编辑列为已实现能力。 |
