# 项目菜单与操作链路

已通过 Playwright 查看原站项目菜单，以及常规设置、域名、详情、克隆、重命名、免费积分、外观和帮助入口。实现按当前服务的真实能力接入。

## 用户操作

点击项目标题展开菜单，点击组件外部或 Escape 关闭。菜单包括仪表板、工作区与套餐、实时可用积分与升级、邀请奖励、项目设置、连接器、克隆、重命名、收藏、详情、外观和帮助。

常规设置提供概览、重命名、克隆、隐私、发布徽章、取消发布和永久删除确认。收藏、隐私、徽章和网址名称存储在 PostgreSQL；主题沿用账户偏好，刷新后保留。发布上传与取消发布沿用真实 MinIO 资源记录。网址名称通过 `/api/sites/{name}` 访问，唯一性由数据库与事务锁保证。

私有项目关闭匿名发布访问；需要先设置为公开才能新发布。旧发布资源设为私有后，公开入口与资源访问都返回 404。取消发布与删除同样撤销公开访问。

## 克隆

- 不调用大模型、不占用构建积分，复制当前源码与现有构建产物，建立新版本快照。
- 保留启动配置、模型、专家选择与项目偏好；重新创建应用数据库 Schema 和角色。
- 排除密钥、Git 元数据、用户附件、代理会话、运行状态、依赖与缓存，不复用容器、GitHub 绑定或发布记录。
- PostgreSQL 使用原生 `pg_dump` 导出结构，使用一致性快照和二进制 `COPY` 复制可选数据，复制序列状态。数据恢复在目标专属角色权限下执行，失败撤销副本项目及数据库资源。
- 使用项目操作锁保护快照，短暂等待预览启动、保存等已有操作；正在构建的项目不允许克隆。
- 所有复制文件（包括 dist）都归属副本的 worker UID，保证后续构建可写入。

## 免费积分

邀请链接绑定新注册用户。受邀用户首次发送有效构建消息时，真实账本发放 10 积分；首次成功发布后邀请人获得 10 积分，每月最多 10 次。事件和额度检查通过行锁保护，重复消息和重复发布不重复发放。每日免费积分与兑换码沿用已有计费链路。

## 自定义域名的部署条件

可添加、移除域名，数据库保存项目归属和验证状态。添加域名后创建 TXT 所有权挑战；检查连接查询真实 DNS。解析按照 [Google Public DNS JSON API](https://developers.google.com/speed/public-dns/docs/doh/json) 处理 TXT、CNAME 和 A 记录。

部署管理员需配置 `PUBLISH_PUBLIC_HOST`，将公网 HTTP/HTTPS 入口反向代理到 preview 服务（容器端口 8002），保留原始 Host，并配置相应 TLS 证书。域名所有者需添加页面提供的 TXT、CNAME（或 A）记录。仅验证成功并指向发布入口的域名参与 Host 路由，且项目必须公开并已发布。

当前内网环境没有可控制的公网域名与 TLS 入口，因此已真实验证域名添加、DNS 未配置状态、移除及权限控制；没有声称验证公网 HTTPS 上线。购买域名按钮打开外部注册商，应用不执行购买。
